# Vera Habitat

Vera Habitat is the project space for Vera's virtual environment: the surrounding environment in which Vera-facing services, interfaces, or simulated context can be composed.

## Current status

The current `main` branch is a scaffold and does not yet contain a complete virtual environment implementation.

Future architecture should state what the habitat provides, what remains external, how authority crosses the boundary, and which parts are presentation, simulation, persistence, or runtime infrastructure.

## Evidence boundary

The project concept does not prove a deployed habitat, active environment, persistent world, or continuous runtime.
